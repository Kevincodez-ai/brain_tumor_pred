# brain_tumor_pred
This is a beginner model to detect brain tumor with the help of tech stacks like Convoluted Neural Networks ( CNN ) , ResNet50 ,  tensorflow + keras etc ... this model on the first run achieved an validation accuracy of around 70 percent  ( may vary) 
Let the accuracy not dihearten you as the results provided are precise and overtime I  plan to implement more models to enhance the accuracy. 
Steps to RUN : 
1 - download datset from kaggle 
2 - input the path of file into the zip extractor code
3 - replace all the file paths with your named file (dataset)  path 
4 - run the code 
5 - after you save the trained model using "model.save()" go to app.py and input the file name of the trained model and run the web app to see the AI in action
